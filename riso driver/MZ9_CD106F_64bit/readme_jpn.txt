 □ご使用上の注意
===============================================================================

(1) 必ずご使用のプリンタ名の付いたプリンタドライバをご使用ください。

(2) 印刷機に対して設定可能な最大印刷枚数は９９９９枚です。
    アプリケーションからは、それ以上の印刷枚数設定が可能な場合がありますが、
    必ず９９９９枚以内で設定してください。
    １００００枚以上に設定された場合は、正しい印刷枚数で印刷されません。

(3) 一つの原稿データの中で、用紙のサイズや向きが混在している場合は、用紙の
    サイズと向きが同じページを選択して印刷してください。
    混在しているページを一度に印刷した場合には、正しく印刷されません。

(4) 極端に薄い色に色づけした文字やイラストは、印刷物上に再現（印刷）されない
    ことがあります。
    濃い色に変更してください。

(5) 極端に薄い色に色づけした罫線を印刷した場合に、実線が点線になったり、
    破線のパターンが変わったりして印刷されることがあります。
    罫線の色を濃い色に変更するか線種やパターンを変更してください。

(6) 複数のプリンタドライバをインストールする場合は、各ドライバのインストール毎
    にコンピュータを再起動し、次のドライバのインストールを行ってください。
    再起動を行わずに次のドライバをインストールすると、正しく動作しない場合が
    あります。

(7) プリンタドライバ、ユーティリティ類の再インストールを行う際には、必ず事前に
    アンインストールを行い、コンピュータを再起動した後に実行してください。
    アンインストール及び再起動を行わなかった場合には、正しくインストール
    できない場合があります。

(8) テストプリントで印刷される、バージョン及びカラー印刷の内容は、Microsoft(R)
    Windows(R)のシステムが表示している内容です。
    プリンタドライバのバージョンは、[印刷設定]ダイアログ上の[バージョン情報]
    ボタンをクリックして表示される、[バージョン情報]ダイアログをご参照ください。

(9) お使いのオペレーティングシステムやアプリケーションによっては、サイズの大き
    な文字が、テキストデータとしてではなくイメージデータ（写真データ）として
    処理される場合があります。
    従って、大きな文字では、[イメージ処理]タブ内の[強制ベタ]をはじめとした、
    文字を対象とした処理が機能しない場合があります。

(10) フリー用紙を指定する場合は、必ずプリンタ・プロパティから用紙のサイズや向き
     を変更してください。

(11) ご使用のアプリケーションによってはアプリケーションでプリンタドライバの
     設定を変更できない場合があります。このような場合はプリンタドライバの
     プロパティの設定とアプリケーションの設定とを合わせてください。

(12) [逆光補正]が[ON]になっている場合、写真やイラストの一部に濃度ムラが
     発生する場合があります。
     以下の方法によって現象が軽減する場合があります。
       ・[イメージ処理]タブ内の[網点線数]の数値を小さくする
       ・[逆光補正]と[エッジ強調]を[OFF]にする
     また、原稿全体をビットマップとして出力する機能を備えたアプリケーションの
    場合には、ビットマップとして出力する事で現象が軽減する場合があります。

(13) JPEGやPDFなどブロック毎に圧縮処理を施す様な画像を印刷する場合、
     [逆光補正]を[ON]に設定すると、周期的なブロックノイズが発生する場合が
     あります。
     [逆光補正]を[OFF]にするか、画像の圧縮率を下げてください。

(14) [逆光補正]を[3]以上に設定した場合、写真の白部分に色が付く場合があります。
     [逆光補正]を[2]以下に設定してください。

(15) Adobe(R) PageMaker(R) またはその他アプリケーションにおける高解像度の
     写真を印刷する場合、[エッジ強調]を[ON]に設定してもほとんど効果があり
     ません。

(16) Adobe Illustrator(R) において、グラデーションがかかったオブジェクトに
     ノイズ(縦線)が印刷される場合があります。
     [逆光補正]と[エッジ強調]を[OFF]にしてください。

(17) Adobe Acrobat(R)、Adobe Reader(R)の印刷ダイアログから、[ページ処理]
     グループBox内にある[ページの拡大/縮小]で、[用紙に合わせる]または
     [大きいページを縮小]を指定し、かつ、[自動回転と中央配置]を[ON]にして印刷
     した場合に、写真部分にブロックノイズが発生することがあります。
     [逆光補正]と[エッジ強調]を[OFF]にしてください。

(18) Adobe Acrobat、Adobe Readerの印刷ダイアログから、[ページ処理]グループ
     Box内にある、[PDFのページサイズに合わせて用紙を選択]を[ON]にして複数ページ
     原稿を印刷した場合、ページごとにジョブが分割されて、印刷機に送られます。
     [PDFのページサイズに合わせて用紙を選択]を[OFF]にしてください。

(19) [連写]など、印面が縮小する機能を使用すると、文字及び罫線の一部が欠ける
     場合があります。

===============================================================================
 □確認されている不具合等について
===============================================================================

(1) 確認されている不具合等に関しての対策およびその他詳細につきましては、
    当社サポートセンターに問い合わせください。

(2) 用紙サイズ入力の際は、単位(mm/inch)を選択した後に数値を入力してください。

(3) 一部のアプリケーションでは、点線が印刷されない場合があります。
    点線を太い点線や破線、実線などの、他の線種に変更してください。

(4) [適用]ボタンがあるダイアログあるいはタブでは、設定内容を変更後、必ず[適用]
    ボタンをクリックして変更内容を適用させてから、次のダイアログあるいはタブへ
    移動してください。
    [適用]ボタンをクリックしないで移動した場合には、設定した内容が有効に
    ならない場合があります。

(5) 地紋や塗りつぶし、文字の網掛けパターンが画面の表示と印刷物で同一にならない
    場合があります。

(6) 一太郎、花子(R)において、網掛けパターンの縦方向にノイズが入る場合があります。
    [逆光補正]と[エッジ強調]を[OFF]に設定してください。

(7) 写真処理を[誤差拡散]に設定した場合、写真部にノイズが発生する場合があります。
    写真処理を[網点]に設定してください。

(8) 用紙サイズ登録において、拡張子がUDPではないファイルを開いたり保存したりし
    ないでください。

===============================================================================
 □使用されるソフトウェアによる制約事項について
===============================================================================

(1) Adobe PageMaker 6.53Jで作成したドキュメントを、用紙を横位置に設定して印刷
    すると、用紙サイズによっては、印字位置がずれて印刷される場合があります。
    ・用紙サイズを若干変更するか、設定を変更した用紙を設定してください。
      （設定方法についてはマニュアルをご参照ください）
    ・Adobe PageMakerを、アップデータで6.53Jにアップデートされている場合は、
      バージョンを6.52J.（ピリオド）に戻して印刷をお試しください。

(2) Microsoft Word の印刷ダイアログから、[拡大／縮小]グループBox内にある
    [１枚あたりのページ数]として複数ページを指定し、かつ、複数部数を印刷
    した場合に、正しい部数で印刷されなかったり、各ページの画像が重なって
    印刷されたりすることがあります。
    一部ずつ複数回に分けて印刷してください。

(3) Microsoft Visio(R) 2000およびMicrosoft Visio 2002からの印刷時にエラーが
    発生する場合があります。
    プリンタドライバーのスプール形式をRAW形式に変えることで回避できる場合が
    あります。

(4) アプリケーションによっては、複数部数印刷時に[部単位で印刷]を[ON/OFF]
    出来ずに、複数部数全てを部単位で印刷してしまう場合があります。
    複数回の製版を行うこととなりますので、ご注意ください。

(5) Microsoft Wordで原稿サイズがA4以外のファイルを開き、最初の印刷時に出力用紙
    サイズの設定を[原稿サイズと同じ]以外に設定した場合、設定どおりに拡大/縮小
    が行われない場合があります。
    以下の手順で印刷することで回避できる場合があります。

    1. 印刷するプリンタとして、ご使用の印刷機に応じたプリンタを選択しておく。
       ご使用の印刷機に応じたプリンタ以外のプリンタを通常使用するプリンタ
       にしている場合や、ご使用の印刷機に応じたプリンタが選択されていない場合
       は、[印刷]ダイアログを開き([メニュー]→[印刷]を選択)、プリンタを
       ご使用の印刷機に応じたプリンタに切り替えた後、[キャンセル]ボタンを
       クリックして、一旦[印刷]ダイアログを閉じてください。
    2. [印刷プレビュー]を表示([メニュー]→[印刷プレビュー]を選択)して閉じる。
    3. [印刷]ダイアログを開き([メニュー]→[印刷]を選択)、プリンタドライバ
       のプロパティを設定後、印刷する。

(6) Adobe PageMakerにおいて、[周囲余白]を[ON]にしても、原稿の右側および下側
    の部分が2mm程度カットされる場合があります。
    以下の手順で印刷することで回避できる場合があります。

    1. [印刷]ダイアログを開き、プリンタのプロパティを開き[周囲余白]を[ON]に
       設定して設定画面を閉じる。
    2. Adobe PageMakerの[印刷]ダイアログが表示された状態で[SHIFT]キーを押下する
       と[印刷]ボタンが[終了]に変わるので、[終了]ボタンを押してダイアログを
       閉じる。
    3. 再度、[印刷]ダイアログを開いて印刷を実行する。

(7) Microsoft Visioで[周囲余白]を[ON]に設定しても、原稿の右および下部分が
    2mm程度カットされる場合があります。
    以下の手順で印刷することで回避できる場合があります。

    1. [印刷]ダイアログを開き、プリンタのプロパティを開き[周囲余白]を[ON]に
       設定して設定画面を閉じる。
    2. [印刷]ダイアログを閉じる。
    3. 再度、[印刷]ダイアログを開いて印刷を実行する。

(8) Adobe InDesign(R)において、縦原稿・横向き印刷・縦用紙でNアップに設定して
    印刷する場合、縦原稿・縦向き印刷・縦用紙として処理され、面付けされる順番
    がプリンタドライバのプロパティで設定したものと異なります。

(9) パターンやテクスチャが画面の表示と印刷物で同一にならない場合があります。

(10) Microsoft Visio 2000において、半透明処理されたイラストを印刷すると、半透明
     部分にノイズが発生する場合があります。
     Microsoft Visio 2000のServicePack2を適用することにより、回避できます。

(11) Microsoft Visio 2007において、不定形用紙サイズの原稿はA4サイズとして
     扱われます。
     以下の手順で印刷することにより回避できる場合があります。

     1. プリンタドライバの[用紙サイズ登録]で、必要な不定形サイズの用紙を登録する。
     2. ファイルメニューの[ページ設定]－[プリンタの設定]で、プリンタの用紙
        サイズを原稿と同じサイズの用紙に変更する。
        原稿が複数ページの場合は、全てのページを変更してください。
     3. [印刷]ダイアログからプリンタのプロパティを開き、[原稿サイズ]に
        あらかじめ登録した不定形用紙を設定し て設定画面を閉じる。
     4. [印刷]ダイアログを閉じる。
     5. 再度、[印刷]ダイアログを開いて印刷を実行する。
        この時、プリンタのプロパティは開かないでください。
        開いた場合は、手順2からやり直してください。

(12) Microsoft PowerPoint(R) 2007において、[高品質で印刷する(すべての影効果
     も印刷されます)]にチェックをいれて印刷を実行すると、イラストの一部が
     写真として扱われるため、所望の印刷物が得られない場合があります。
     [高品質で印刷する(すべての影効果も印刷されます)]のチェックを外して
     印刷することをお勧めします。

(13) Microsoft Word 2007 や Microsoft Excel(R) 2007において、半透明を含む
     透過オブジェクトを使用した原稿を、アプリケーションを閉じずに連続して
     印刷すると、一定の印刷物が得られず、印刷するごとに印刷結果が異なります。
     同一データを複数回印刷するときは、印刷するごとにアプリケーションを
     一度閉じてください。

(14) WindowsXPにおいて、
     Microsoft Word 2007にServicePack3を適用した場合、
     写真処理を[誤差拡散]に設定すると、写真部分が極端に薄く出力されることがあります。
     その場合、写真処理を[網点]に設定するか、
     原稿をPDFデータに変換してから印刷することをお勧めします。

(15) Microsoft Excel 2010において、オブジェクト（文字、イラスト、写真）の一部が
     正しいタイプのオブジェクトとして処理されず、所望の印刷物が得られない場合があります。
     （イラストオブジェクトの一部が写真として処理されるなど。）
     その場合、原稿をPDFデータに変換してから印刷することをお勧めします。

(16) Windows8において、
     Printer Driverセットアップ画面で[取扱説明書(PDFファイル)を読む]ボタンをクリックしても
     取扱説明書を表示できないことがあります。
     その場合は、CDドライブの[Manual]フォルダ内にあるPDFファイルを直接開いてください。

(17) 本製品は、Windows 8の「デスクトップアプリ」に対応しています。
     「WinRTアプリ」からは印刷できません。
