★ RISO PRN — auto-decoded thermal-head bitmap

Bitmap decode attempt (raw, manual)

Drop a file, then guess a width and starting offset. Common RISO master widths at 600 dpi: A3 long-edge = 9921 dots, A3 short-edge = 7016 dots, A4 long-edge = 7016, A4 short-edge = 4960. If the data is compressed (JBIG), this raw bit-rendering won't make sense — we'll need to add a decoder once we see what's actually in the file.
What markers we're scanning for
  • PJL / @PJL — HP Printer Job Language commands (often wrap the actual data)
  • ESC sequences (0x1B + letter) — printer control bytes
  • JBIG/JBIG2 magic — \x97\x4A\x42\x32\x0D\x0A\x1A\x0A (JBIG2 header)
  • "tHsG" — RISO halftone-file magic (in case fonts/data are inlined)
  • "RISO" / "MZ9" — printer model strings
  • 0xFFD8 — JPEG SOI
  • "PNG" at offset 1 — PNG signature
  • Long runs of 0x00 / 0xFF — likely raw 1-bit raster (white/black solid areas)
